Getting Started

This is a static website and does not require a build process.

1. Clone the repository
git clone https://github.com/lokesh15kl/portfolio.git
cd portfolio
2. Run locally

Open:

index.html

directly in your browser.

Alternatively, serve the project using any local static file server.

Usage

Open index.html in a browser to view the portfolio.

Deployment

This project is suitable for deployment using GitHub Pages because it uses static HTML, CSS, and JavaScript.

GitHub Pages
Open the repository Settings.
Select Pages.
Under Build and deployment, select Deploy from a branch.
Select the main branch.
Select / (root).
Click Save.

Once deployed, GitHub will provide the public website URL.
